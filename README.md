# BEE · Robot Simulator: download site

The download page for BEE, a free 3D robot simulator for the 2026–27 season, served with GitHub Pages:
https://mariusandrei123.github.io/bee-simulator/

The builds (Windows, macOS, Linux) are attached to the [Releases](https://github.com/MariusAndrei123/bee-simulator/releases).
The page links to `releases/latest/download/<file>`, so a new release does not need a site change, as long as the file names stay the same.
