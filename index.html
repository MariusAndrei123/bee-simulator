Features

Practice without
waiting for the robot

Write the code, tune the auto and train the drivers while the real robot is still in pieces.

01 / RUN YOUR CODE

Your real Java,
on a simulated robot

Your TeamCode compiles against a simulated control hub and drives the robot exactly like on the real one. Telemetry, logs and errors show up as you play.

  • hardwareMap, motors, encoders, servos, IMU, Pinpoint, Limelight and sensors
  • Pedro Pathing and Road Runner run as they do on the robot
  • Java is built in: nothing to install
02 / ROBOT GARAGE

Bring your
own robot

Import your CAD in the CAD Studio and it drives on the field with your mass, speed and motors. Or build a robot from blocks in minutes: intake, turret, launcher, camera and sensors.

  • CAD Studio: GLB, FBX, OBJ, 3MF or STL, as detailed as you want, with turrets that turn
  • Motor names and directions set by hand, or read from your Driver Station XML or code (Beta lab)
  • Checks the 18 in start size for you
03 / AUTO BUILDER

Draw the auto.
Get the code.

Click points on the field or stack blocks like go to, intake, shoot and wait until. Test it in the simulator, then take the generated Java OpMode to your robot.

  • Path mode and blocks mode
  • Timeline of the 30 s, so you see what fits
  • One click from drawing to Test in sim
04 / PLAY

Full matches,
real pressure

2:30 matches with autonomous and driver control, bots on both alliances, scoring, fouls and a match clock. Or free play and short challenges to train your drivers.

  • Gamepad or keyboard
  • Records, replays and an online leaderboard
  • Smooth on a laptop, sharp on a big screen
05 / ONLINE NEW

Play with your
team online

Make a private room and send the code to your friends, or jump into quick play with whoever is online. Up to four players, two per alliance, with bots on the empty spots. In AUTO, every robot runs its own player's auto.

  • Private rooms with a 5-letter code, or quick play
  • Your Auto Builder auto runs in AUTO, from its own START
  • Your robot answers right away: it drives on your own computer
  • Works across networks and countries, even on mobile data

FAQ

Questions

Is BEE really free?

Yes. No account, no ads, no paid version. Download it and play.

Do I need to install Java or anything else?

No. A small Java runtime with the compiler comes inside the download, so your TeamCode compiles and runs right away. Only Intel Macs need a JDK 17+ installed (from adoptium.net).

macOS says it can't open BEE

BEE is not signed by Apple yet. Open it once, click Done, then go to System Settings → Privacy & Security and click Open Anyway. You only do this the first time.

Windows shows a SmartScreen warning

The app is not signed by Microsoft yet. Click More info → Run anyway. Keep the java and runtime folders next to BEE.exe.

How do I play online with my friends?

PLAY → Online → Create a private room, then send the 5-letter code. Your friends type it and press Join. The one who made the room presses Start match. In AUTO your robot runs the auto you picked in the Auto Builder (Java OpModes don't run online: they become Smart Auto). If Windows Firewall asks, allow BEE. You don't need to be on the same Wi-Fi: it works across networks and countries, even on mobile data. Let the player with the best internet make the room.

How do I update BEE?

From version 1.7, when a new version is out, the main menu shows a green Update available button. Press it: BEE downloads the new version, checks it, closes and starts again updated. Your robots, autos and settings stay. If you have an older version, download 1.7 from this page once.

Where are my robots and autos saved?

In your user folder (Godot/app_userdata/ftc_project): on macOS under ~/Library/Application Support, on Windows under %APPDATA%, on Linux under ~/.local/share. A new version of BEE keeps them.

Is BEE an official app?

No. BEE is an independent project. It is not affiliated with, sponsored by or endorsed by FIRST®. See the notice at the bottom of this page.
