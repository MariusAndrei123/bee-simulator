What you can do

The BEE field: POLLEN, NECTAR, FLOWERS and the HIVE, with the scoring, fouls and match clock of the game manual.

Play matches

Full matches, autonomous only, driver control, free play and short challenges, with bots on the field. Local records, replays and an online leaderboard.

Run your own Java

Your TeamCode compiles against a simulated Control Hub: hardwareMap, motors, encoders, servos, IMU, Pinpoint, Limelight, distance and color sensors. The simulator drives the robot from your code.

Robot Garage

Build the robot from blocks: intake, turret, launcher, camera and sensors. Import its CAD (STL / GLB), set mass, speed and motors, and check the 18 in start-size rule.

Auto Builder

Draw a path or build an autonomous from blocks, test it in the simulator, and export it as a ready-to-use FTC OpMode.

First start

BEE is not signed by Apple or Microsoft yet, so the first time your system asks you to confirm.

Windows

  1. Unzip BEE-windows.zip.
  2. Open the BEE folder and run BEE.exe.
  3. If SmartScreen appears: More info → Run anyway.

macOS

  1. Unzip BEE-macos.zip and move BEE.app to Applications.
  2. Open it. macOS says it cannot check the app: click Done.
  3. System Settings → Privacy & Security → Open Anyway.

Linux

  1. tar -xzf BEE-linux.tar.gz
  2. Run BEE/BEE.x86_64.
  3. Keep java/ and runtime/ next to it.

Your robots, autos and settings are saved in your user folder (Godot/app_userdata/ftc_project), so a new version keeps them.
